# Getting help

These places cover every repository in the [salah-kit](https://github.com/salah-kit) organization.

## Read first

- **SalahTimes**, the calculation engine: its [README](https://github.com/salah-kit/SalahTimes#readme) and its documentation at <https://salah-kit.github.io/SalahTimes/>.
- **SalahKit**, the app layer: its [README](https://github.com/salah-kit/SalahKit#readme) and its documentation at <https://salah-kit.github.io/SalahKit/>.
- **SalahStarter**, the template for a new app: its [README](https://github.com/salah-kit/SalahStarter#readme) walks from "Use this template" to a working widget.
- **Salah**, the macOS app: its [README](https://github.com/salah-kit/Salah#readme) covers building and using it.

## Ask a question

Ask in GitHub Discussions:

- [SalahTimes Discussions](https://github.com/salah-kit/SalahTimes/discussions) for calculation methods, high-latitude rules and the JSON vectors;
- [SalahKit Discussions](https://github.com/salah-kit/SalahKit/discussions) for schedules, timetables, widgets, alerts and the UI building blocks.

Include the package version, the platform, and a short piece of code when you can.

## Report a problem

Open an issue in the repository it concerns. The issue forms ask for what's needed to act on it:

- **Bug**: something that doesn't work as documented.
- **Calculation method**: a method's parameters differ from what its authority publishes.
- **Timetable**: computed times differ from a published timetable for a place.
- **Translation**: a prayer name or other text is wrong in a language.
- **RFC**: a change to a package's public API, with the app that needs it.

## Report a vulnerability

Don't open a public issue. Follow the [security policy](SECURITY.md).
